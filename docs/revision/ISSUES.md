# 整改前检查

基线版本为 Git 标签 `baseline-before-gis-revision`，对应提交 `5f2901a`。原部署运行在本机 8080，基线页面截图见 [before](before/)。整改在同一项目工作副本开展，部署前会停机备份原数据库和运行包。

| 实测或代码问题 | 位置及原因 | 整改与验证 |
| --- | --- | --- |
| 俯瞰图采用矩形台座，建筑朝向单一，路网多数为规整正交；没有可重复的北向平面对照 | `scene.json` 主要由会务图人工概化，三维镜头缺少正射模式 | 结合可用 GIS 或校园参考视图记录方位和地标，补独立北向核对界面。保留编号，再核对入口、路段和可达性。 |
| 食堂和宿舍立面偏重复、绿化散布，道路边缘与室外空间的信息不足 | `scene/models.js` 和 `scene/landscape.js` 多用通用体块与随机散点 | 改善重点楼体、道路层次、成列植栽及光照，复拍校园、综合楼、食堂和入口步行视角。 |
| 路线可计算，缺少同图对比和多站自动排序 | `Campus.java` 实现 Dijkstra 并按请求顺序串联 | 提取统一步行图，引入 A*、可核对的精确与启发式优化，验证同比距离及保存恢复。 |
| 地图保存直接替换当前快照，草稿仅在浏览器，历史无法恢复 | `CampusStore.java`、`Admin.vue` 只有当前修订号和 JSON 交换 | 增加数据库草稿和历史，发布与恢复共用引用及几何校验，版本与反馈可关联。 |
