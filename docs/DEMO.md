# 课程答辩演示 · 7 分 30 秒

提前启动服务并准备两个浏览器窗口。普通窗口登录 `student`，独立隐私窗口登录 `admin`。准备一条当日临时行程和一条现场反馈，演示结束后可删除临时行程。后台修改前可导出场景，演示完导入旧场景并保存。

| 时间 | 操作 | 讲解重点 |
| --- | --- | --- |
| 0:00–0:45 | 展示地图概览，小地图定位，拖动旋转和缩放 | 校园地图是功能主界面，游客可直接用。 |
| 0:45–1:35 | 搜索“综合楼”，点击主楼，切换到图书馆入口，再进入第一人称移动 | 综合楼斜向框架来自公开照片的特征，图书馆是同一综合楼的入口。窗列和树木采用实例化绘制。 |
| 1:35–2:45 | 打开路径规划，北门为起点、综合楼和图书馆为途经点、食堂为终点，计算并暂停、继续模拟 | 每段由 Dijkstra 解出，路径与真实数据图中的节点和边对应，距离为估算。 |
| 2:45–3:35 | 保存路线、收藏地点，在个人空间刷新查看两条记录 | 共享地点 ID、Spring Security 会话、后端账户归属。 |
| 3:35–4:35 | 新增当日安排，尝试输入冲突时段，再打开“初见南湖”确认首站 | 服务端检查行程重叠与导览顺序，用户手动确认导览站点。 |
| 4:35–5:25 | 普通用户提交针对建筑或道路的纠错，管理员标记处理中并回复 | 展示普通用户和管理员权限，以及反馈闭环。 |
| 5:25–6:45 | 管理员导出场景，修改综合楼高度或颜色并保存。切回地图刷新，显示变化，再导入旧场景 | 场景草稿和修订号，入口、道路穿楼、业务引用以及导入校验。 |
| 6:45–7:30 | 将中央步道内一条路设为关闭，重新计算北门至食堂后恢复道路 | 关闭边退出步行图，算法重新寻找路径，图断开时提示不可达。可选展示一次无效导入。 |

结束时简述环境为 Vue 3、Three.js、Java 21 和 Spring Boot。MySQL 与 H2 均通过本地验证。
