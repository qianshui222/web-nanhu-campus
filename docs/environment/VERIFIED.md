# 本轮实际验证

Windows 本地使用 Java 21、Vite 7.1.7、Vue 3、Three.js 0.180、Spring Boot 3.5.7，运行原版和新版浏览器页面。验收使用独立 H2 文件库，部署前校验并备份原 H2 文件和原运行包。历史地图和旧账号继续保留。

## 结果

| 用例 | 实际结果 |
| --- | --- |
| 基线和迁移 | 逐项比对原版 14 个地点的坐标、宽深、高度、角度、入口，保留全部旧路段 ID。带已有账号及图书馆收藏的 v2 结构副本升级后仍可登录并查询收藏。已有手改地图或主动恢复历史版时，启动迁移保留管理员状态。 |
| 建筑和道路 | 29 个有效地点，每个从北门可路由到指定入口。24 个实体建筑记录全部形成有限包围盒的生成组，15 个补录地点逐一搜索和选中。道路检查通过，补录前后的地标可在北向对照中查看。 |
| 跨时区与昼夜 | Playwright 在 America/Los_Angeles 和 Europe/Paris 两个浏览器时区读到相同的北京时刻。受控跨午夜预览从 11 月 23 日切到 24 日。11 月 23 日清晨采样方位 113.1°，12:30 高度 39.0°、方位 186.3°，黄昏方位 247.0°。夜间窗光和路灯可见。 |
| 真实天气 | 应用实际请求了 Open‑Meteo。一次成功返回的气象有效时间是北京时间 23:00，后端拉取为 23:11:27，天气码 0。也观察到首轮上游不可用，页面保持可操作，后续请求恢复。 |
| 气象故障 | 独立测试源验证超时无缓存、缓存命中、429 后保留旧值并标过期、上游恢复、缺测字段保持 null。晴、阴、雨、雪和缺测效果用页面的明确测试模式录制。 |
| 行程算法 | 明天 12:45 北门出发、食堂停 10 分钟、14:00 前到综合楼可行，截止压缩至 12:46 时不可行。在测试管理员维护食堂只在 19:00–20:00 开放后，规划明确提示开放冲突。测试了没有打印地点和预报不覆盖的情况。 |
| 地图与保存 | 表单计算真实道路路线，页面展示每站、各段和截止状态，登录保存后刷新可从个人空间重新打开。浏览器回归日志没有未处理错误。 |
| Agent 工具与动作 | 独立受控协议测试使用脚本响应，验证工具往返、指代、餐饮图层、选中、播放/停止、未知地点、非法编辑动作拒绝、上游错误和计划入库。地图、时间、路径和数据库仍由实际应用执行。 |
| 真实模型 | 当前未获得可调用的模型基址、模型名及必要凭证。本地模型下载尝试未完成。真实自然语言推理联调仍待进行，部署默认显示服务未配置。 |

最终晴天俯瞰在 1440×880 SwiftShader 软件渲染环境中抽样为 **12 FPS、64 次绘制调用、57,600 三角面、24 个几何、1 张纹理**。合批前同版模型抽样为 385 次绘制调用。合批减少了调用数，这次样本中帧率仍为 12 FPS。新地图包含更多建筑和三角面，帧率未达到上轮较简单场景的样本值。

## 改动位置

- 记录、校准和迁移在 `scene.json`、`scene-v2.json`、`calibration-anchors.json`、`Campus.java`、`CampusStore.java` 和 `schema.sql`。
- 模型、昼夜和气象渲染在 `models.js`、`MapScene.vue`、`atmosphere.js`、`campusEnvironment.js`、`EnvironmentPanel.vue`、`CampusEnvironment.java`。
- 时间窗、工具协议和页面动作在 `Routing.java`、`CampusPlanner.java`、`CampusAgent.java`、`AgentPanel.vue`、`TimedPlanCard.vue`、`App.vue` 和 `Admin.vue`。
- `verification/accept-environment.cjs` 验收建筑、时区、预览和规划持久化。请在独立测试数据库运行，因为脚本会临时发布开放时间、恢复原场景并保存验收行程。

GIS 几何仍为近似。现场开放时间、遮蔽属性和打印地点当前没有完整已核实资料。预报仅覆盖供应商提供的时间，真实模型服务配置后需补验自然语言完整链路。
