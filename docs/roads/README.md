# 南湖漫游 · 道路与导航校准记录

## 基准与来源

修改前使用部署中的地图 v3。代码基准为 `8dbf4d9`，Git 标记为 `baseline-before-road-alignment`。原种子已保存为 [scene-v3.json](../../backend/src/main/resources/scene-v3.json)。两版的 29 个地点（包含全部 24 个实体楼体）整条记录一致，`JSON.stringify(places)` 的 SHA-256 均为 `e2e845dd65847a3b9472a7efd860097c1f1197989b9fbc24c6fca9c692052d5c`。建筑入口引用、地点编号、路口编号、道路编号、边界、水岸和场景距离换算系数保持一致。

在 [华中师范大学校园 GIS](https://gis.ccnu.edu.cn/) 切换南湖校区，打开道路图层并保存 [校园范围](gis-nanhu.png) 和 [道路图层](gis-road-layer.png)。使用 1600 × 1000 浏览器视口，沿用既有校准的图像原点 (780, 535)，东向基向量 (2.30, 1.00)，南向基向量 (−1.65, 1.90)。场景 X 向东、Z 向南。GIS 图有倾斜视角、标签遮挡和楼体透视。对照图用于检查相对走向、拐弯和连接关系。宽度来自场景估计，距离继续使用 1.8 米／场景单位的既有估算系数。没有 GIS 道路矢量、现场测量或米级精度结论。

| --- | --- | --- |

| 入口接入 | 原有入口节点有的位于建筑边缘，有的只可定位到公共接入点，旧版缺少依据说明。 | 保留地点入口引用，修正食堂南侧道路到既有接入点。将餐厅南侧原 P--W2 连接改为 P → canteen-in，并以折点通过食堂侧道路。图书馆和综合楼沿各自接入点与 Q 公共路口连接，综合楼经前庭步道转弯。GIS 未能确认的门洞继续标记为待核实。 |

## 验证与缺口

- 在独立 H2 数据库通过 [道路验收](../../verification/accept-roads.cjs) 逐条验证五组正反向路线、折线距离、A* 与 Dijkstra 的长度一致、起终点相同、多途经点、避开台阶、道路关闭、不可达、发布校验与回滚。[实测记录](api-verification.json)
- 封闭 P--M 后，宿舍 15 栋到综合楼仍可经食堂侧道路到达，约 469.6 m。北门接入关闭时返回 HTTP 422。后台拒绝脱离路口的折线端点、穿越建筑的折点和直接开放待核实历史边。
- GIS 可见道路无法确认西南侧 U--V 和南端 d12-in--Z 的步行连续性，也无法确认湖侧 G--d11-in、F--G、PLJ--G 是否开放且绕过附属设施。这五条历史边停用，北门目前无法导航到宿舍 11 栋、宿舍 12 栋和心理学院实验基地。地点仍可浏览，已有记录继续引用相同 ID。
- 部分宿舍门洞、图书馆入口台阶与无障碍过渡、围栏开口、道路宽度和实际地面坡度需要现场核实。图上的避台阶仅使用已录入的台阶属性。
- Agent 的确定性规划继续调用共用路线服务。真实模型调用受现有接口配置限制，本轮未实测外部模型。
